# Anger and the acceptance of political violence

Replication package for **“Anger and the acceptance of political violence.”**

**Work in progress:** This project is ongoing. The analyses and replication materials are not yet finalized and may change.

## Replication materials

The replication package is being prepared. Further code, supporting files, software requirements, and instructions for reproducing the results will be added as they become available. Scripts may be inspected but data will not be made available until manuscript submission.
